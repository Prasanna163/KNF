NCIForge 1.0.0 - Windows x64
================================

INSTALL

Run:

  NCIForge-Setup-1.0.0.exe

The installer creates the NCIForge application, desktop and Start Menu
shortcuts, and an uninstaller. Python, Node.js, and PyTorch do not need to be
installed separately.

PYTORCH AND GPU SUPPORT

CPU-only PyTorch 2.11 is included and works on every supported system.

If setup detects an NVIDIA GPU, it offers to download and validate optional
CUDA 12.8 PyTorch. This requires an internet connection and several gigabytes
of free disk space. Select No to continue with CPU PyTorch.

CUDA packages are stored under:

  %LOCALAPPDATA%\NCIForge\runtime\cuda-site-packages

The NCIForge uninstaller removes this optional CUDA runtime.

WINDOWS SECURITY NOTICE

This build is not digitally signed. Windows SmartScreen may show an
"Unknown publisher" warning until a code-signing certificate is configured.

VERIFY THE DOWNLOAD

Compare the installer against SHA256SUMS.txt:

  certutil -hashfile NCIForge-Setup-1.0.0.exe SHA256

Expected installer SHA-256:

  AF7F740561044325BB3F0E59AB38353AFAA4CE4D8D2DA9E2A132070035853C4E
